# 📡 Freshdesk Intelligence Dashboard

La pestaña **Exportación por institución/contacto** organiza los archivos locales
por nombres normalizados e IDs. Exporta a Excel tickets creados o con movimientos en un rango, sus actividades y cambios de estado. Permite recuperar descripciones y respuestas completas desde
Freshdesk con una API key. Elegir nombre y fechas y pulsar Descargar data genera directamente el Excel. Ver
[el procedimiento de extracción](EXPORTACION_CONTACTOS_INSTITUCIONES.md).
